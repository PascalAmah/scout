# Scout PRD

## Vision

Scout is an AI workspace for discovering startup opportunities, understanding companies, generating tailored application materials, and tracking outreach in one place.

> Discover → Save → Enrich → Match → Generate → Apply → Track

## Problem

Startup hiring is fragmented across YC, Wellfound, Product Hunt, Techstars, company sites, LinkedIn and founder profiles. Candidates manually collect information, rewrite resumes, craft outreach, and track applications.

## Goals

- Save opportunities from anywhere.
- Build a personal startup knowledge base.
- Match opportunities against a user's experience.
- Generate personalized resumes, cover letters, and outreach.
- Track the complete application pipeline.

## Primary Users

- Software Engineers
- Designers
- Product Managers
- AI Researchers
- Students seeking internships

## Product Principles

1. Browser extension is an input tool, not the product.
2. AI should reduce manual work.
3. Every saved startup becomes structured knowledge.
4. Personalization beats keyword matching.

## Recommended Tech Stack

### Frontend

- React (Vite)
- TypeScript
- TanStack Router (file-based routing)
- TanStack Query (server state, caching)
- Tailwind CSS
- shadcn/ui

### Extension

- Plasmo (Manifest V3)

### Backend (Recommended)

Use **Python + FastAPI**.

Reasons:

- Excellent AI ecosystem.
- First-class async support.
- Automatic OpenAPI docs.
- Great performance.
- Easy integration with LangChain, LlamaIndex, OpenAI, Gemini, sentence-transformers, and ML tooling.

Suggested architecture:

- FastAPI
- SQLAlchemy 2.0
- Alembic
- PostgreSQL + pgvector
- Redis
- Celery (or Dramatiq) for background jobs
- Pydantic
- JWT/Authlib
- APScheduler for scheduled sync jobs

### Storage
