01 — Color

Palette

Emerald is earned, not everywhere — it marks the brand mark, primary actions, and a positive match/outcome. Charcoal and near-black carry structure and text. Paper is the only background. Three muted status hues (amber, slate, brick) exist purely to keep the CRM legible — they're desaturated enough to defer to emerald, never compete with it.

04 — Elevation

Borders & shadow

Structure comes from a 1px line first, shadow second — matching the brand guide's flat, border-led card style rather than a heavy floating-card look. Shadow only appears to signal interactivity (hover) or true overlay (modals, dropdowns).

Resting

1px solid var(--line). No shadow. This is the default state for every card, panel, and input.

Hover / interactive

Border unchanged, shadow-md added, 1px lift. Used on clickable cards and rows only.

Overlay

shadow-lg, reserved for modals, dropdowns, and the extension popup — anything floating above the page.

05 — Buttons

Actions

Charcoal is the default primary — it's what most actions use. Emerald primary is reserved for the single most important action on a screen (Generate, Save, Apply-adjacent), so it keeps its signal value instead of becoming wallpaper.

08 — Match Ring — signature component

The lens, reused

Scout's logo is a lens: an emerald ring around a charcoal center with a small glare. Instead of a generic donut chart for match scores, the score indicator is the logo mark — the ring's fill is the score, the core holds the number. It appears at three sizes and recolors by confidence band, so the brand mark and the product's core mechanic are literally the same shape.

12 — Motion

Principles

Motion in Scout explains state changes in an async product — it never performs. Every AI action is an honest queued → running → done sequence, so motion should confirm progress, not simulate it.

→

Ring fill animates on data arrival

The match ring sweeps from 0 to its score once, when a real score loads — never as ambient decoration or looping.

→

Running state pulses gently

The amber "running" dot has the only looping animation in the system — a slow 1.6s opacity pulse, signalling active background work.

→

Cards lift 1px on hover

A minimal, fast (150ms) elevation change signals interactivity without a bounce or scale effect.

→

Reduced motion respected

All transitions collapse to instant state changes under prefers-reduced-motion — the ring still fills, just without the sweep.

13 — Voice

Content notes

Scout narrates AI work honestly and names actions by what the user controls, never by system internals.

Do

"Enriching… usually takes ~2 min" · "Saved to Scout" · "Re-enrich" · "Generate resume" → toast reads "Resume generated"

Avoid

"Processing webhook…" · "Submit" (says nothing about what happens) · Silent gaps with no state label · Apologetic error copy
